# MeshFactory Quality Assurance and Code Generation Standards

This instructions file provides persistent guidance for all Copilot interactions in the MeshFactory workspace.

## Quality Checks (MANDATORY - Applied to All Code Changes)

Every code modification, migration, or refactor must pass these quality checks:

### Phase 1: Syntax Validation
```powershell
& "C:/xampp_devops_test/php/php.exe" -l <file>
```
- Must output: `No syntax errors detected`
- Applied to every touched file
- Applied domain-wide when abstracts or paths change

### Phase 2: Encoding Validation
```powershell
$bytes = [System.IO.File]::ReadAllBytes($file) | Select-Object -First 3
# Expected: 3C 3F 70 (<?php)
# NOT: EF BB BF (UTF-8 BOM)
```
- Files must be UTF-8 without BOM
- Fix with: `[System.IO.File]::WriteAllText($path, $content, [System.Text.UTF8Encoding]::new($false))`

### Phase 3: Domain-Wide Verification
When abstract classes migrate or paths change:
- Run quality checks on all concrete implementations in affected domain
- Verify all parent class dependencies updated correctly
- Check for static method calls (must use `parent::`)

## Organization Standards

### Abstract Classes
- Location: `/src/MvpLounge/MeshFactory/Abstract/`
- Naming: `FactoryElement{Domain}Abstract.php`
- Domains: Field, FieldInput, Fieldset, Form, Link, Table
- Namespace: `MvpLounge\MeshFactory\Abstract`

### Concrete Implementations
- Location: `/src/MvpLounge/MeshFactory/Element/{Domain}/`
- Examples: `TextInput.php`, `RadioInput.php`, `TableCell.php`, `AjaxForm.php`
- Parent class requires: `__DIR__ . '/../../Abstract/FactoryElement{Parent}Abstract.php'`

### Enum Authority
- Location: `/src/MvpLounge/MeshFactory/Enum/`
- Files: `FactoryElement.php`, `FactoryElementAttribute.php`, `FactoryElementFieldType.php`, `FactoryElementPrimativeType.php`
- Add all supported attributes BEFORE implementing factory methods

All files in this codebase follow strict namespace organization:


UTF-8 no-BOM is REQUIRED for all namespaced files.

## Fluent Interface Pattern

All `add*()` methods MUST return `$this` to enable method chaining:

```php
public function addLabel($label): FactoryElementFieldAbstract
{
    $this->FactoryElementFieldLabel = $label;
    return $this;  // ← Required for fluent interface
}

// Usage:
$field->addLabel('Name')->addPlaceholder('Enter name')->addRequired(true);
```

## Parent Method Calls in Concrete Implementations

When overriding parent methods, use `parent::` not static class calls:

```php
// ✓ CORRECT
public function getFactoryModel(): array {
    return array_merge(
        parent::getFactoryModel(),
        ['content' => $this->content]
    );
}

// ✗ WRONG
public function getFactoryModel(): array {
    return array_merge(
        FactoryElementAbstract::getFactoryModel(),
        ['content' => $this->content]
    );
}
```
